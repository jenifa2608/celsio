# CELSIO WATTSMART

### Smart Household Electricity Monitoring & Management System

CELSIO WATTSMART is an IoT-based student project concept designed to help households monitor electricity consumption and manage connected electrical loads.

## Project Overview

The project explores smart electricity monitoring, remote load control and household energy management using an ESP32-based prototype.

## Features

- Electricity monitoring concept
- ESP32-based IoT architecture
- OLED display for information
- Remote load control concept
- Smart energy management

## Technologies Used

- ESP32
- Embedded C++
- Wokwi Simulator
- OLED Display
- IoT

## Simulation

**Wokwi Simulation:** https://wokwi.com/projects/474936354223730689

## Project Status

Student prototype and simulation. Features are under development and have not been validated in a real household.
